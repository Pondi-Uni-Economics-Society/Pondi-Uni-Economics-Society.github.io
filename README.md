# Economics Society website

Public website for the Economics Society, Department of Economics, Pondicherry University.

- The site is built from `index.html` and the `assets/` folder.
- The site is intended for GitHub Pages at https://pondi-uni-economics-society.github.io/.
- Archive entries should point to approved materials in [Society-Archive](https://github.com/Pondi-Uni-Economics-Society/Society-Archive).
- Large videos and photo collections should be hosted on an approved external platform and linked from the archive.
- Do not publish private, confidential, or restricted information.
